Trumpet

A B2B sales enablement platform. I built a comprehensive design system and a reusable filtering framework, giving the team consistent foundations that could be applied across the product.

My role
Product Designer
Scope
Product Design · Design System
Platform
Web Application

Overview

As Trumpet grew, its basic design foundation needed to support more features and increasingly complex workflows.

I created a design system that turned recurring interface decisions into reusable components and patterns. A key part of this work was a unified filtering system that could be applied to any product page without redesigning the experience each time.

My role

I built on the existing basic foundation to create a comprehensive design system, covering design tokens, components, interaction states, and shared workflows.

  • Defined foundational tokens and built a reusable Figma component library.
  • Created a flexible filtering system for use across product pages.
  • Established consistent patterns for tables, save bars, bulk actions, and archive workflows.
  • Prepared component variants, interaction states, and developer handoff.

Challenge

The existing foundation lacked the depth needed for a growing product. Shared components required more complete states and consistent behavior, while filtering needed to accommodate different data and page contexts.

The challenge was to support these differences through one adaptable system that remained straightforward for both users and the product team.

Approach

I consolidated recurring interface elements into shared components, supported by design tokens and defined interaction states.

For filtering, I designed a common structure that could accommodate page-specific criteria while preserving the same interaction model. This allowed the team to configure filters for different contexts using established building blocks, giving users familiar controls wherever they worked.

I applied these foundations to product workflows to refine the system and ensure the components worked together.

Outcome

Trumpet gained a comprehensive design system and a filtering framework that could be reused across the product.

The team could introduce filtering on different pages without creating a new solution each time. For users, this established a familiar way to narrow information across workflows. For designers and engineers, it reduced repeated design work and provided clear, reusable patterns for extending the product.
